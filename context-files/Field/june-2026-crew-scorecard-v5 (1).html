Methodology Notes

  • W2 Utilization % = W2 kW / 100kW capacity (2 crews × 50kW/week). W2 crews: Benjamin Roby, Humberto Llanes.
  • Scheduled to Complete = Arrivy install tasks scheduled that week with COMPLETE status. kW from QuickBase system size.
  • Total Completed = QuickBase Install Completed Date in that week. All June installs show as completed (100%).
  • 1-touch = install completed with zero post-install Arrivy tasks (inspection, service, drop-off) before PTO date (or July 21 if no PTO yet). Any return visit = NOT 1-touch.
  • W2 install cost per watt = labor cost / W2 kW. Labor cost pending from Penny. kW denominator shown for each week.
  • Crew classification: W2 = Roby, Llanes, Radebaugh. Sub = Lanier, Ish & Gio, Breaux (Disrupt the Grid). Unknown = no Arrivy entity assignment.
1-Touch Rate — Context
1-touch rate is very low (5/55 = 9%). This is because nearly every install has at least one post-install Arrivy task (inspection accompaniment, plan drop-off, service visit, photo retake). This is a systemic workflow pattern, not necessarily an install quality issue — most post-install visits are standard inspection accompaniment or monitoring setup, not defect corrections. Consider whether James wants to exclude routine inspection accompaniment from the 1-touch definition.
